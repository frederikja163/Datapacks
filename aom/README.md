# Age Of Minecraft (AOM)


This is a datapack mod inspired by millenaire and survival challenges.

Create villages, fill the villages with houses and watch the villagers work for you.

## Commands

|Command|Requirements|Description|
|-|-|-|
|`/trigger aom.help`|None|Prints a help message on how to get started.|
|`/trigger aom.start_village`|Looking at sign with name of city|Starts a new village with the name of the city|
|`/trigger aom.create_building`|Looking at sign with name of valid building<br>Be part of a village|Creates the building on the sign*|

> \* All buildings are written with lowercase letters. Example: Lumbermill is `lumbermill`.

When typing commands and looking at signs, the signs will get turned into lecterns representing said building. If a building is out of date, update it by removing the lectern. By right clicking on a building you can delete it using the delete button in the toolbar.

## Buildings

### Townhouse
Contains an overview of the city as a whole. Here you can leave and join the city.

### House
For every house you build you will get one villager you can put to work.

### Lumbermill
